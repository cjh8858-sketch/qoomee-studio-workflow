# 썸네일 템플릿 가이드

제공된 썸네일 레퍼런스 4장의 공통 시각 규칙과 변형 레이아웃을 정리한 재사용용 가이드입니다. 원본을 복제하기보다 주제와 자료에 맞게 이미지, 문구, 강조색을 새로 구성합니다.

## 공통 디자인 원칙

### 화면 비율과 프레임

- **기본 비율:** 16:9 가로형
- **권장 작업 크기:** 1280 × 720 px 또는 1920 × 1080 px
- **외곽 프레임:** 얇은 청록색 테두리/여백을 반복 요소로 활용합니다. 이미지 기준으로 약 16~20 px의 프레임이 보이지만, 실제 제작 크기에 따라 비례 조정합니다.
- **안전 영역:** 제목과 핵심 로고/이미지는 가장자리에서 최소 5% 안쪽에 배치합니다. 플랫폼별 미리보기 크롭을 고려해 특히 하단의 긴 문구가 잘리지 않게 확인합니다.
- **배경:** 검정/짙은 회색 또는 흰색/밝은 그라데이션을 선택해 주제 이미지와 제목의 대비를 확보합니다. 한 썸네일 안에서 배경 스타일을 과도하게 섞지 않습니다.

### 제목과 문안

- **핵심 문구:** 한눈에 읽히는 짧은 제목을 우선하고, 불필요한 설명은 줄입니다.
- **문안 구조:** `대상/문제 → 얻는 결과/효과 → 주제 또는 도구` 순서로 구성합니다.
- **강조 위계:** 주요 키워드 하나는 청록색 채움 또는 밝은 포인트 색으로, 나머지 제목은 흰색/검정으로 구분합니다.
- **외곽선:** 밝은 배경이나 복잡한 화면 위에서는 검정 외곽선/그림자로 글자 형태를 분리합니다. 어두운 배경에서 흰 제목을 쓸 경우 배경 명도를 낮춰 대비를 확보합니다.
- **행 수:** 제목은 보통 1~2줄을 목표로 합니다. 3줄 이상 필요한 경우 문구를 줄이거나 화면 캡처/이미지 크기를 재배치합니다.
- **금액·시간·성과:** `10분`, `비용 ZERO`처럼 구체 수치를 강조할 수 있지만, 실제 콘텐츠에서 확인 가능한 내용만 사용합니다. 효과나 성과를 과장하지 않습니다.

### 시각 자료와 구성

- **주 피사체:** 실제 제품, 앱/웹 화면, 제작물, 인물 중 콘텐츠의 핵심을 대표하는 하나를 가장 크게 배치합니다.
- **보조 자료:** 비교 주제는 로고/앱 아이콘을 나란히 두고, 튜토리얼은 실제 화면 캡처를 보여 줍니다. 제품 소개는 실제 제품 컷이나 상세페이지 시안을 함께 보여 줍니다.
- **목업:** 휴대폰 화면이나 카드형 시안을 넣을 때는 제목과 경쟁하지 않도록 1~3개로 제한하고, 주제와 직접 연관된 이미지를 사용합니다.
- **브랜드 로고:** 설명 대상 도구의 로고는 비교/튜토리얼 문맥에서만 사용하고, 로고 원본·상표 사용 가이드를 준수합니다.
- **시각적 초점:** 썸네일을 작게 봐도 주제와 핵심 문구를 구분할 수 있도록 배경 요소와 장식을 줄입니다.

## 참고 색상

다음은 제공된 이미지에서 관찰한 **화면상 근사치**입니다. 원본 디자인 파일에서 픽셀을 추출한 공식 브랜드 색상은 아니며, 레퍼런스의 시각적 방향을 재현할 때만 참고합니다.

| 역할 | 근사 HEX | 사용 가이드 |
|---|---|---|
| 청록 프레임/포인트 | `#12BFC5` | 바깥 테두리, 제목의 핵심 키워드, 작은 강조 요소 |
| 옅은 민트 배경 | `#A4E5E2` | 밝은 스타일의 배경 또는 제목 강조 영역 |
| 딥 틸 보조색 | `#087E82` | 짙은 배경의 보조 패널/장식 |
| 블랙 | `#080A0B` | 다크 배경, 화면 목업 주변, 제목 대비 |
| 화이트 | `#FFFFFF` | 다크 배경 위 큰 제목 |
| 비비드 블루 | `#2861E8` | 도구/기능을 표시하는 보조 포인트에 제한적으로 사용 |
| 따뜻한 오렌지 | `#F2A000` | 라벨 또는 제한적인 보조 강조. 청록과 같은 비중으로 남용하지 않음 |

**색상 규칙:** 기본적으로 검정/흰색/청록을 바탕으로 하고, 썸네일 하나에서 추가 강조색은 한 가지 정도만 선택합니다. 밝은 글자는 밝은 배경 위에 직접 놓지 말고 외곽선이나 어두운 패널을 둡니다.

## 반복 가능한 레이아웃 4종

### A. 비교·선택형

**참고:** `thumb_nail (1).jpg`

- 흰색 또는 옅은 민트 배경
- 비교할 앱/서비스 로고를 중앙에 배치하고 `VS` 또는 비교 기호로 연결
- 상단에 짧은 캡슐형 라벨
- 하단에 굵은 제목 1~2줄
- 제목 일부는 민트색 채움과 검정 외곽선으로 강조

**문안 틀**

```text
[한눈에 정리 / 비교 안내]
[도구 A] VS [도구 B]
[누가/언제 어떤 도구를 선택할까?]
```

### B. 앱·도구 튜토리얼형

**참고:** `thumb_nail (2).jpg`, `thumb_nail (8).jpg`

- 검정/짙은 회색 배경
- 중앙 또는 한쪽에 스마트폰 목업/실제 앱 화면 캡처를 크게 사용
- 도구 로고는 화면 주변에 작게 배치
- 큰 제목은 하단에 놓고, 핵심 시간·비용·난이도 표현을 청록으로 강조
- 글자가 캡처 화면에 겹치면 불투명 패널이나 외곽선을 추가

**문안 틀**

```text
[초보자용 / 비용·시간 등 근거 있는 짧은 훅]
[도구/기능명]으로
[만들 결과 또는 해결할 문제]
```

### C. 상품·상세페이지 콜라주형

**참고:** `thumb_nail (3).jpg`

- 검정 배경 위에 제품/상세페이지 사례를 3~5개 가로로 배열
- 좌우/상단에는 사례, 하단에는 큼직한 핵심 제목
- 제목은 흰색을 기본으로 하고 한 단어/구절만 청록으로 강조
- 작은 말풍선/손글씨 라벨은 보조 설명용으로만 사용
- 사례가 잘려 보이지 않도록 카드마다 여백과 크기 규칙을 맞춤

**문안 틀**

```text
[사례/결과를 요약하는 짧은 문장]
[핵심 이점] + [주제/비결]
```

### D. 밝은 정보 정리형

**참고:** `thumb_nail (1).jpg`

- 흰색 상단에서 민트/청록 그라데이션 하단으로 이어지는 배경
- 앱 로고, 아이콘, 짧은 비교 정보를 상단에 정돈
- 중앙/하단 제목은 검정 외곽선과 민트 채움으로 가독성을 강화
- 밝고 친절한 정보·비교·입문 콘텐츠에 사용

**문안 틀**

```text
[대상/상황]
[무엇을 비교하거나 정리했는지]
[읽은 뒤 얻게 될 결과]
```

## 제목 카피 공식

주제와 사실관계에 맞는 문장만 골라 사용합니다.

- **초보자 문제 해결:** `[초보자/대상]도 [원하는 결과] 만드는 [도구/방법]`
- **시간 절약:** `[시간] 안에 [완성할 결과] — [도구/기능] 활용법`
- **비교/선택:** `[A] vs [B], [상황]에는 무엇을 선택할까?`
- **실제 사례:** `[제품/프로젝트] 사례로 보는 [핵심 비결]`
- **비용/효율:** `[확인된 비용 조건]으로 [작업 결과] 만들기`
- **단계별 가이드:** `[핵심 작업] 처음부터 끝까지, [단계/도구] 정리`

```text
영상/콘텐츠 주제:

시청자가 얻을 결과:

강조할 단어/수치:
근거 또는 주의할 표현:
레이아웃: [비교·선택 / 앱 튜토리얼 / 상품 콜라주 / 밝은 정보 정리]
배경 톤: [다크 / 라이트]
주 피사체: [앱 화면 / 제품 / 인물 / 결과물]
보조 로고/화면 자료:
강조색: [청록 기본 + 선택색 1개]
계정/브랜드 표기:
```

## 게시 전 체크리스트

- [ ] 16:9로 제작했고 작은 미리보기에서도 제목과 주제가 즉시 보입니다.
- [ ] 한 썸네일에 전달할 메시지를 하나로 제한했습니다.
- [ ] 제목은 짧고, 모바일에서 읽을 수 있을 만큼 큽니다.
- [ ] 청록 강조는 핵심 키워드에만 적용하고 추가 색상은 절제했습니다.
- [ ] 사진/캡처 화면과 제목이 서로 가리지 않으며 대비가 충분합니다.
- [ ] 실제 화면·제품·로고를 사용했으며 권리와 출처를 확인했습니다.
- [ ] 시간, 비용, 성능, 수상 등 주장은 영상 내용과 일치하고 근거가 있습니다.
- [ ] 자극적이거나 단정적인 표현이 콘텐츠 내용을 과장하지 않습니다.
- [ ] 주요 텍스트와 로고가 안전 여백 안에 있고, 플랫폼 미리보기에서 잘리지 않습니다.
- [ ] 오탈자와 도구/브랜드 이름을 최종 확인했습니다.

## 재사용 시 주의

- 레퍼런스 이미지는 스타일 참고용입니다. 이미지, 상표, 문구를 허가 없이 복제하지 않습니다.
- HEX 값은 시각적 근사치일 뿐 공식 브랜드 가이드가 아닙니다. 채널 또는 고객의 브랜드 규정이 있으면 해당 규정을 우선합니다.
- 썸네일 문구는 콘텐츠에서 실제로 설명하거나 증명하는 내용과 일치해야 합니다.
