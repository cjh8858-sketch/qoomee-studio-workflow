# 카드뉴스 템플릿 가이드

세 가지 레퍼런스 이미지의 공통적인 편집 감각과 서로 다른 표지 구성을 정리한 재사용용 가이드입니다. 이미지를 그대로 복제하기보다, 주제에 맞게 사진·문구·강조 방식을 새로 적용합니다.

## 레퍼런스 파일

- [cardnews.jpg](./cardnews.jpg) — 인물 사진과 강한 타이포그래피를 결합한 에디토리얼 표지
- [cardnews2.jpg](./cardnews2.jpg) — 배경 사진 위에 콘텐츠 목업을 겹친 마케팅 레퍼런스형 표지
- [cardnews3.jpg](./cardnews3.jpg) — 인물/현장 사진 위에 짧은 훅과 형광 포인트를 사용한 소셜형 표지

## 공통 디자인 원칙

### 포맷과 레이아웃

- **기본 비율:** 세로형 4:5
- **권장 작업 크기:** 1080 × 1350 px
- **안전 여백:** 상·하·좌·우 약 64 px 이상을 기준으로 제목, 로고, 핵심 정보를 배치합니다. 플랫폼 UI나 썸네일 크롭에 따라 가장자리 글자가 잘리지 않는지 확인합니다.
- **이미지:** 인물, 제품, 현장, 오브젝트처럼 주제와 직접 연결되는 사진을 화면의 주 배경 또는 핵심 요소로 사용합니다.
- **텍스트 위 사진:** 제목 뒤에 어두운 그라데이션/반투명 오버레이를 더하거나 글자 외곽 대비를 확보해 사진 위에서도 쉽게 읽히도록 합니다.
- **레이어링:** 자료 화면, 포스터, 카드/스크린샷 목업을 겹칠 경우 크기와 위치를 달리해 깊이를 만들되, 핵심 제목과 경쟁하지 않게 합니다.

### 타이포그래피와 문안

- **표지 훅:** 핵심 주장을 한눈에 읽히는 짧은 문장으로 씁니다. 가능하면 2~4행 안에 정리하고, 조사·수식어보다 주제어와 동사를 강하게 둡니다.
- **위계:** `작은 분류/시리즈명 → 큰 제목 → 보조 설명/출처` 순으로 중요도를 나눕니다.
- **강조:** 문장 전체를 꾸미기보다 핵심 단어 한두 개만 컬러 블록, 형광색, 밑줄, 크기 차이로 강조합니다.
- **본문 카드:** 한 장에는 메시지 하나를 담고, 본문은 제목과 짧은 설명/근거로 분리합니다. 긴 문단은 여러 장으로 나눕니다.
- **폰트:** 레퍼런스의 정확한 서체는 확인되지 않았습니다. 유사한 인상을 내고 싶다면 한글은 획이 명료한 고딕 계열, 짧은 영문 라벨은 필요에 따라 세리프/산세리프를 조합합니다. 한 카드 안의 서체 종류는 2종 이내를 권장합니다.

### 컬러 사용

아래 색상은 레퍼런스 이미지에서 화면상 보이는 인상을 바탕으로 한 **근사 팔레트**입니다. 정확한 원본 픽셀 추출값이나 특정 브랜드의 공식 색상은 아닙니다.

| 쓰임 | 참고 색 | HEX 근사치 | 사용 방법 |
|---|---|---|---|
| 기본 제목/본문 | 화이트 | `#FFFFFF` | 어두운 사진이나 어두운 오버레이 위 제목 |
| 바탕/어두운 면 | 블랙 | `#111111` | 본문 대비, 하단 정보 영역, 배경 오버레이 |
| 강한 소셜 강조 | 네온 그린 | `#00E83A` | 한두 개 키워드나 짧은 강조 블록에 제한적으로 사용 |
| 정보 라벨/CTA | 비비드 블루 | `#1677F2` | 카테고리 라벨, 짧은 정보 태그에 사용 |
| 사진/보조 색 | 이미지에서 추출 | 프로젝트별 선택 | 사진의 주요 색과 조화시키고 팔레트를 과도하게 늘리지 않음 |

- 각 시리즈/브랜드에 자체 팔레트가 있으면 그 색을 우선합니다.
- 레퍼런스의 형광 초록과 파랑을 동시에 강조색으로 남용하지 않습니다. 표지마다 핵심 강조색 한 가지를 먼저 정합니다.
- 흰색 글자를 밝은 하늘/벽 위에 놓거나 밝은 색 글자를 흰 바탕에 놓지 않습니다. 필요하면 어두운 오버레이, 그림자, 불투명 패널을 추가합니다.

## 표지 스타일 3가지

### A. 에디토리얼 인물 표지

**레퍼런스:** `cardnews.jpg`

- 인물/오브젝트 클로즈업을 크게 사용합니다.
- 사진 위에 어두운 오버레이를 적용하고, 큰 흰색 제목을 하단 또는 중앙에 배치합니다.
- 작은 카테고리 문구와 보조 카피를 제목 위에 둡니다.
- 영문 소제목, 작은 코너 라벨, 밑줄/검은 바탕의 단어 등으로 잡지형 리듬을 더할 수 있습니다.
- 인물 얼굴이나 주 피사체를 제목으로 가리지 않도록 텍스트 위치를 먼저 조정합니다.

**문안 구조**

```text
[작은 시리즈/주제 라벨]
[짧은 도입 문구]
[큰 제목: 핵심 주장 또는 질문]
[선택: 영문 보조 라벨/계정명]
```

### B. 마케팅 레퍼런스 콜라주 표지

**레퍼런스:** `cardnews2.jpg`

- 큰 배경 사진을 캔버스 전체에 깔고, 필요하면 흐림/명도 조정으로 전경을 돋보이게 합니다.
- 실제 콘텐츠를 보여 주는 카드, 게시물, 자료 화면 목업을 2~3개 크기와 깊이를 달리해 겹칩니다.
- 파란색 등 한 가지 색의 캡슐형 분류 라벨을 제목보다 위에 둡니다.
- 제목은 하단에 크고 간결하게 놓고, 브랜드/출처 표기는 제목 아래 또는 하단에 정돈합니다.
- 목업 안의 텍스트가 읽히지 않더라도 콘텐츠 유형이 보이도록 실제 결과물 또는 제작한 예시를 사용합니다.

**문안 구조**

```text
[카테고리 라벨]
[콘텐츠/사례 목업 2~3개]
[큰 제목: 대상 + 얻을 정보/가치]
[브랜드 또는 출처]
```

### C. 소셜 훅/밈형 표지

**레퍼런스:** `cardnews3.jpg`

- 현장감 있는 사진을 배경으로 사용하고, 짧고 강한 문구를 사진 위에 배치합니다.
- 큰 흰색 제목을 화면 중앙 또는 하단에 두며, 중요한 단어 하나를 형광색 블록으로 강조할 수 있습니다.
- 상단/하단에 계정, 시리즈, 출처 라벨을 작은 크기로 보조합니다.
- 시선을 빠르게 끌되, 제목만 읽어도 내용이 오해되지 않게 표현합니다.
- 과장된 훅은 실제 본문 내용과 일치해야 하며, 인물/고객의 민감한 정보나 동의 없는 얼굴 노출을 피합니다.

**문안 구조**

```text
[짧은 질문/상황 훅]
[핵심 단어를 한 가지 색으로 강조한 제목]
[한 줄 맥락 또는 설명]
[계정/콘텐츠 출처]
```

## 전체 카드뉴스 권장 흐름

아래는 주제에 맞게 조정하는 기본 구성입니다. 카드 수는 정보량에 따라 늘리거나 줄입니다.

| 카드 | 역할 | 들어갈 내용 |
|---|---|---|
| 1 | 표지 | 주제를 설명하는 강한 훅, 제목, 시리즈/출처 |
| 2 | 문제/맥락 | 독자가 공감할 상황, 왜 이 주제가 중요한지 |
| 3 | 핵심 내용 1 | 첫 번째 핵심 포인트와 짧은 근거/사례 |
| 4 | 핵심 내용 2 | 두 번째 핵심 포인트, 시각 자료나 예시 |
| 5 | 핵심 내용 3 | 세 번째 핵심 포인트 또는 비교/체크리스트 |
| 6 | 실행/요약 | 독자가 바로 적용할 행동, 핵심 내용 요약 |
| 7 | 마무리/CTA | 저장·공유·문의 등 한 가지 다음 행동, 계정/출처 |

### 본문 카드 레이아웃

- 상단에 작은 섹션 번호 또는 주제 라벨을 둡니다.
- 제목은 한 카드의 핵심 메시지를 한 문장으로 요약합니다.
- 설명은 1~3개의 짧은 덩어리로 구성하고, 한 문단은 2~4줄을 넘기지 않는 것을 목표로 합니다.
- 표, 숫자, 인용, 사진, 아이콘 중 시각 요소를 한 가지 선택해 설명을 돕습니다.
- 카드마다 번호, 색상, 제목 위치, 여백 체계를 유지해 한 세트로 느껴지게 합니다.
- 정보 출처나 저작권 표기는 해당 카드 또는 마지막 카드에서 찾기 쉽게 표시합니다.

## 카드별 원고·디자인 작업 템플릿

각 카드마다 아래 블록을 복사해 사용합니다.

```text
### 카드 [번호] — [카드의 역할]
- 핵심 메시지:
- 제목(가능하면 1문장):
- 본문(짧은 문장/불릿):
- 시각 자료(사진/목업/표/아이콘):
- 강조할 단어:
- 출처/크레딧:
- 디자인 메모(배치/배경/색):
```

## 게시 전 체크리스트

- [ ] 표지만 읽어도 주제와 독자 가치가 보입니다.
- [ ] 각 카드가 핵심 메시지 하나만 전달합니다.
- [ ] 표지 제목은 짧고, 모바일 미리보기 크기에서도 읽힙니다.
- [ ] 사진 위 텍스트 대비가 충분하고 피사체를 불필요하게 가리지 않습니다.
- [ ] 강조색은 핵심 단어에만 사용하고 카드 전체의 색 체계가 일관됩니다.
- [ ] 인물, 브랜드, 작품, 캡처 이미지 사용 권한과 출처를 확인했습니다.
- [ ] 수치/성과/인용은 근거가 있고 사실과 의견을 구분했습니다.
- [ ] CTA는 한 가지 행동으로 명확합니다.
- [ ] 4:5 미리보기와 실제 게시 화면에서 가장자리 글자/로고가 잘리지 않습니다.
- [ ] 오탈자, 날짜, 연락처, 링크, 계정 표기를 최종 확인했습니다.

## 재사용 시 주의

- 레퍼런스는 디자인 참고용입니다. 이미지, 문구, 브랜드 로고를 복제하거나 출처 없이 재사용하지 않습니다.
- 이 템플릿의 근사 HEX 값은 공식 브랜드 가이드가 아닙니다. 게시물 대상 브랜드의 공식 팔레트가 있으면 해당 규정을 따릅니다.
- 자극적인 표지 카피는 실제 콘텐츠의 사실관계와 일치하도록 작성합니다.
- 한 장에 글을 모두 넣기보다, 독자의 이해 흐름에 맞춰 내용을 여러 카드로 나눕니다.
