## 공통 디자인 시스템

### 캔버스와 정렬

- **기본 비율:** 가로형 16:9
- **권장 크기:** 1920 × 1080 px. 화면 발표나 PDF용 크기에 맞춰 비례 조정합니다.
- **배경:** 흰색 또는 아주 옅은 중립색을 기본으로 두고, 프로젝트 작품의 색을 돋보이게 합니다.
- **좌우 여백:** 제목·로고·본문·이미지의 시작/끝선을 일정하게 맞춥니다. 가장자리와 콘텐츠 사이에 충분한 여백을 둡니다.
- **헤더:** 왼쪽 상단에 큰 페이지/분야 제목, 오른쪽 상단에 스튜디오 로고를 놓고, 아래에 굵은 남색 가로선을 긋습니다.
- **본문:** 페이지의 목적에 따라 한 가지 그리드 체계를 선택합니다. 이미지와 문장 기준선을 정렬하고 카드 사이 간격을 균일하게 유지합니다.

### 타이포그래피

- **제목:** 굵고 응축된 산세리프 계열의 인상을 사용합니다. 영어 대문자 섹션명(`SERVICE TYPE`, `MEET OUR TEAM`) 또는 큰 한글 분야명을 쓸 수 있습니다.
- **본문:** 읽기 쉬운 산세리프체를 사용하고, 제목보다 충분히 작은 크기로 설정합니다.
- **위계:** `섹션 제목 → 프로젝트/서비스명 → 한두 문장의 설명 → 이미지 캡션` 순서로 나눕니다.
- **정렬:** 같은 페이지 안에서 제목/본문 정렬 방식을 통일합니다. 설명은 결과물의 디자인 의도와 사용자/브랜드 가치를 짧게 설명합니다.
- **텍스트 양:** 이미지가 결과물을 말하게 하고, 본문은 목적·해결 과제·핵심 특징만 남깁니다. 화면에서 읽기 어려운 작은 설명은 축소하지 말고 줄이거나 별도 페이지로 옮깁니다.

### 컬러

아래 HEX는 레퍼런스 이미지에서 보이는 화면 색을 바탕으로 한 **시각적 근사치**이며, 공식 브랜드 색상표의 확정값은 아닙니다.

| 역할 | 참고 HEX | 사용 가이드 |
|---|---|---|
| 다크 네이비 | `#1C275F` | 상단 제목, 가로 구분선, 페이지 번호/기본 강조 |
| 화이트 | `#FFFFFF` | 기본 배경 및 여백 |
| 본문 차콜 | `#272727` | 설명문, 작은 캡션 |
| 중립 그레이 | `#777777` | 부가 설명·보조 캡션 |
| 청록 포인트 | `#18A5A6` | 팀/강점 번호, 일부 보조선 등 제한적인 강조 |
| 프로젝트별 색 | 프로젝트마다 선택 | 작품·패키지·포스터의 고유 팔레트를 보존하고, 페이지 장식색으로 강제 통일하지 않음 |

- 기본 페이지는 남색과 흰색으로 정돈하고, 각 프로젝트의 색상은 작품 이미지 안에서 충분히 보여 줍니다.
- 레퍼런스의 네온 그린, 오렌지, 민트 등은 개별 포스터/패키지의 프로젝트 팔레트입니다. 모든 페이지 공통 포인트 색으로 사용하지 않습니다.
- 정확한 로고 색상 및 서체 규정은 공식 원본 자료가 있으면 해당 자료를 우선합니다.

## 반복 가능한 페이지 레이아웃

### A. 서비스 소개형

**참고:** `portfolio (4).jpg`, `portfolio (18).jpg`, `portfolio (19).jpg`

- 공통 헤더 아래 본문 상단을 좌우 2단으로 나눕니다.
- 왼쪽에는 `서비스 상세 소개` 같은 섹션 라벨을 크게 둡니다.
- 가운데 세로 선으로 구분하고, 오른쪽에는 프로젝트/서비스명과 설명을 둡니다.
- 하단 또는 페이지 아래쪽에는 패키지/제품 결과물을 1~5개 배치합니다.
- 설명은 디자인 요소 나열로 끝내지 말고, 컨셉이 브랜드나 사용자 경험에 어떻게 연결되는지 씁니다.

```text
[헤더: SERVICE TYPE | 로고]
[왼쪽 섹션명] | [프로젝트명]
               [컨셉과 디자인 의도 1~2문장]
[하단: 대표 결과물 사진/목업 1~5개]
```

### B. 결과물 갤러리형

**참고:** `portfolio (2).jpg`, `portfolio (6).jpg`, `portfolio (8).jpg`

- 설명을 최소화하고 포스터·패키지·제품 목업 자체를 넓게 보여 줍니다.
- 한 페이지에서 작품 수가 많으면 대표 이미지 1개를 크게 두고 나머지를 보조 썸네일로 구성합니다.
- 프로젝트 팔레트와 화면 비율을 존중하고, 작품 간 간격과 외곽선을 일관되게 맞춥니다.
- 프로젝트 명칭이나 적용 매체는 짧은 캡션으로 표시합니다.

```text
[헤더: 분야명 | 로고]
[짧은 프로젝트 요약(선택)]
[대표 작품 크게] + [보조 적용 사례/디테일 컷]
[작품명 · 적용 매체 캡션]
```

### C. 브랜드 시스템/응용형

**참고:** `portfolio (5).jpg`, `portfolio (7).jpg`

- 로고/캐릭터/심볼 등 핵심 자산을 크게 보여 줍니다.
- 컬러 팔레트, 패턴, 타이포그래피 등의 시스템 정보는 작은 견본으로 곁들입니다.
- 굿즈, 패키지, 행사 그래픽 등 실제 적용 사례를 별도 영역에 배열합니다.
- 한 페이지에서 `핵심 자산 → 시각 규칙 → 적용 결과`의 흐름이 보이도록 합니다.

```text
[헤더: SERVICE TYPE | 로고]
[브랜드/캐릭터/로고의 대표 이미지]
[팔레트 또는 구성 요소]
[패키지·굿즈·행사 그래픽 등 실제 응용]
[각 적용물의 간단한 캡션]
```

### D. 이커머스/홍보마케팅 사례형

**참고:** `portfolio (9).jpg`, `portfolio (10).jpg`

- 쇼핑몰 메인 화면과 상품 상세 화면을 한 페이지에 나란히 배치합니다.
- 상품 사진, 제품 상세 콘텐츠, 실제 판매 페이지가 한 프로젝트에서 어떤 역할을 하는지 보여 줍니다.
- 이미지 캡처의 글씨가 너무 작아지지 않도록 화면 전체를 축소하기보다 핵심 구간을 크롭해 확대할 수 있습니다.
- 가격·리뷰·판매량·혜택 등 변동 정보는 최신성이 확인되지 않으면 흐리게 처리하거나 제외합니다.
- 성과 수치가 있으면 출처와 측정 시점을 확인하고, 단순 디자인 시안과 실제 운영 화면을 명확히 구분합니다.

```text
[헤더: 홍보마케팅 | 로고]
[쇼핑몰 메인/브랜드 영역]
[상품 상세페이지 핵심 화면]
[제품 컷/상품 목록]
[수행 범위와 실제/시안 여부 캡션]
```

### E. 팀/역량 소개형

**참고:** `portfolio (3).jpg`

- 강점이나 작업 방식을 3개 안팎의 열로 나눕니다.
- 각 열은 번호, 짧은 제목, 관련 현장 사진, 한두 문장 설명 순서로 구성합니다.
- 번호와 세로 구분선에 청록/블루 계열을 보조색으로 쓸 수 있지만, 기본 헤더와 본문 남색 체계는 유지합니다.
- 일반적인 수식어 대신 실제 작업 방식이나 확인 가능한 경험을 설명합니다.

```text
[헤더: MEET OUR TEAM | 로고]
[01 핵심 역량] | [02 접근 방식] | [03 협업 방식]
[사진]          | [사진]          | [사진]
[근거 있는 설명] | [근거 있는 설명] | [근거 있는 설명]
```

## 권장 포트폴리오 구성 순서

프로젝트 소개 자료는 아래 순서를 기본으로 하되, 작업 성격에 따라 불필요한 페이지를 줄입니다.

1. **프로젝트 개요:** 프로젝트명, 분야, 기간(확인된 경우), 수행 범위
2. **과제/배경:** 고객 또는 사용자의 필요와 해결할 문제
3. **컨셉:** 핵심 아이디어와 디자인 방향
4. **시스템/디자인 개발:** 로고·컬러·캐릭터·패키지 등 핵심 요소
5. **적용 결과:** 제품, 패키지, 쇼핑몰, 포스터, 굿즈 등 실제 매체
6. **효과/결과:** 확인 가능한 결과만 기재하고 출처·기간을 덧붙임
7. **마무리:** 요약 또는 문의/다음 행동

```text
의뢰 배경과 해결 과제:

핵심 컨셉:

사용한 이미지/자료의 권리 확인:
실제 운영물 또는 시안:
성과(근거 및 측정 시점 포함):
```


## 품질 체크리스트

- [ ] 모든 페이지에서 상단 분야명, 로고, 구분선의 위치와 크기가 일관됩니다.
- [ ] 한 페이지에서 전달할 핵심 메시지는 하나이며, 설명이 이미지와 중복되지 않습니다.
- [ ] 대표 결과물은 충분히 크게 보여 주고, 작은 이미지가 지나치게 많지 않습니다.
- [ ] 이미지 비율을 왜곡하지 않았고, 패키지/제품/화면의 중요한 부분이 잘리지 않았습니다.
- [ ] 실제 운영 결과와 컨셉 시안을 구분해 표기했습니다.
- [ ] 가격·리뷰·판매량·성과 정보는 정확성과 기준 시점을 확인했습니다.
- [ ] 고객 로고, 인물 사진, 제품 사진 등 자료 사용 권리와 공개 동의를 확인했습니다.
- [ ] 본문과 캡션의 글씨 크기가 실제 발표/열람 환경에서 읽힙니다.
- [ ] 남색/흰색의 기본 체계와 프로젝트별 고유 팔레트가 서로 충돌하지 않습니다.
- [ ] 오탈자, 프로젝트명, 날짜, 크레딧과 문의 정보를 확인했습니다.

## 재사용 시 주의

- 레퍼런스는 레이아웃과 정보 구성 참고용입니다. 작품 이미지, 고객 로고, 문구를 권리 확인 없이 재사용하지 않습니다.
- 표에 적힌 색상은 화면 관찰을 바탕으로 한 근사치이며, 공식 Qoomee Studio 색상 규격으로 간주하지 않습니다.
- 확인되지 않은 고객명·성과·제작 범위를 추정해 추가하지 않습니다.
