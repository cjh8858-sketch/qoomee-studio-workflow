# Instagram 게시물 템플릿

Qoomee Studio의 공개 프로필, 피드 미리보기, 게시물 캡션과 하이라이트 주제를 참고해 만든 게시물 기획·작성 가이드입니다. 계정은 디자인기획, 브랜드 제품·패키지, 구미 로컬 문화예술 프로젝트를 소개하며 작업 결과뿐 아니라 현장, 제작 의도, 실무 팁, 창작자 경험도 콘텐츠로 다룹니다.

## 참고한 계정 방향

- **계정 표기:** `꾸미스튜디오 | 디자인×문화예술기획`, `@qoomee_studio`
- **소개 분야:** 디자인기획 × 문화예술 교육 / 브랜드 제품·패키지 디자인 기획 / 구미 로컬 중심 문화예술 프로젝트
- **피드에서 관찰되는 형식:** 릴스, 캐러셀, 현장 사진/기록, 포스터형 그래픽, 제품·브랜드 사례, 인터뷰/개인 서사
- **하이라이트 주제:** AI 영상 콘텐츠, 디자인·AI 교육, 문화예술기획·교육, 브랜드 디자인
- **콘텐츠 톤(해석):** 친근하고 직접적인 한국어, 분야/행동을 강조하는 이모지와 체크 표시, 제작 배경과 과정이 담긴 설명형 캡션

위 내용은 프로필과 열람 가능한 게시물 일부에서 관찰한 방향입니다. 게시물 전체의 성과 분석이나 공식 편집 가이드로 간주하지 않습니다.

## 콘텐츠 기둥

| 기둥 | 다룰 만한 소재 | 권장 형식 |
|---|---|---|
| 프로젝트 사례 | 브랜딩, 로고, 패키지, 상세페이지, 홍보물, 영상 제작 | 캐러셀, 릴스, 전후 비교 |
| 제작 과정 | 기획 의도, 현장 스케치, 시안 발전, 문제 해결 과정 | 릴스, 과정 사진 캐러셀 |
| 지역·문화예술 | 구미 로컬, 행사/공공 프로젝트, 문화예술교육 현장 | 현장 릴스, 참여형 캐러셀 |
| 디자인·AI 실무 팁 | AI 영상/이미지 도구, 디자인 프로그램, 콘텐츠 제작 방법 | 단계별 캐러셀, 튜토리얼 릴스 |
| 사람과 관점 | 창작자 경험, 협업, 배운 점, 인터뷰/성과 | 인물 릴스, 짧은 에세이형 캐러셀 |

한 게시물은 한 기둥을 중심으로 하고, 다른 주제는 보조로만 연결합니다.

## 게시물 형식별 구성

### A. 캐러셀/카드뉴스

```text
1장 — 표지: [대상/문제] + [얻을 가치]
2장 — 맥락: 왜 이 주제를 다루는지
3장 — 핵심 내용 1 또는 작업 전 상황
4장 — 핵심 내용 2 또는 해결 과정
5장 — 결과/적용 사례
6장 — 요약 또는 바로 적용할 팁
마지막 장 — CTA + 계정/출처
```

- 한 장에는 핵심 메시지 하나만 담습니다.
- 표지 제목은 본문 내용과 일치시킵니다.
- 단계형 정보에는 번호와 짧은 문장을 활용하고, 이미지 안 글자가 작아지면 장수를 늘립니다.
- 프로젝트 소개라면 `과제 → 접근/컨셉 → 결과물 → 적용/배운 점` 흐름을 고려합니다.

### B. 릴스/영상 게시물

```text
첫 1~2초 — 결과물 또는 궁금증을 보여주는 훅
본문 — 상황/문제 → 기획·제작 과정 → 결과/핵심 팁
마무리 — 핵심 요약과 단일 CTA
화면 요소 — 짧은 자막, 필요한 경우 작업명/출처
```

- 시작 화면에서 영상의 주제와 볼 이유가 바로 전달되도록 합니다.
- 자막은 음성 없이 봐도 의미가 통하게 작성하고, 화면 가장자리의 UI 영역을 피합니다.
- 제작 과정이나 도구 사용을 소개할 때 실제 사용한 내용만 밝힙니다.

### C. 단일 이미지/현장 기록

```text
이미지: [결과물/현장/인물 중 핵심 하나]
캡션 첫 문장: [무엇을 했는지 또는 핵심 관점]
본문: [배경] → [진행/의도] → [결과/느낀 점]
마무리: [감사/질문/문의 중 하나]
```

현장 사진은 개인정보, 참여자 동의, 기관/고객의 공개 허용 범위를 확인합니다.

## 캡션 작성 템플릿

```text
[첫 문장: 핵심 결과, 문제, 또는 독자가 공감할 상황]

이번 콘텐츠에서는 [프로젝트/주제]를 다뤘습니다.
[배경 또는 해결하려던 문제를 1~2문장으로 설명]

기획/제작에서 중요하게 본 점은
✅ [핵심 포인트 1]
✅ [핵심 포인트 2]
✅ [핵심 포인트 3 - 필요한 경우]

[결과, 적용, 배운 점을 구체적으로 설명]

궁금한 점이나 다음에 다뤘으면 하는 주제가 있나요?
[CTA 하나]

기획·제작: 꾸미스튜디오 / @qoomee_studio
[협업자·기관·이미지 출처·지원 표기 - 해당하는 경우]

#꾸미스튜디오 #[주제] #[지역/분야] #[서비스]
```

## 문체와 CTA

- 기본 문장은 따뜻하고 직접적인 한국어로 씁니다.
- 이모지는 문단 구분이나 항목 표시를 도울 때만 사용하고, 문장마다 반복하지 않습니다.
- 친근한 표현을 쓰더라도 고객/참여자를 낮추거나 대상의 어려움을 희화화하지 않습니다.
- CTA는 한 게시물에서 한 가지를 우선합니다: 저장, 의견 댓글, 공유, 프로필 링크 확인, 협업 문의 중 하나.
- “무조건”, “100%”, “대박” 등 단정적 표현은 실제 근거와 맥락이 없으면 쓰지 않습니다.

## 게시 전 체크리스트

- [ ] 첫 화면/첫 문장에서 주제가 명확합니다.
- [ ] 본문이 하나의 콘텐츠 기둥과 한 가지 독자 가치에 집중합니다.
- [ ] 캡션의 주장, 숫자, 수상/성과, 도구 설명은 확인 가능한 근거가 있습니다.
- [ ] 광고/지원/협업/출처 표기를 빠뜨리지 않았습니다.
- [ ] 사진 속 인물과 작업물의 공개 동의 및 사용 권리를 확인했습니다.
- [ ] 영상 자막, 이미지 내 텍스트, 해시태그의 오탈자를 확인했습니다.
- [ ] 개인 연락처나 참여자의 민감한 정보를 불필요하게 공개하지 않았습니다.
- [ ] CTA와 링크가 현재 유효합니다.
