# 콘텐츠 에이전트 (Content Agent)

## 역할
- 카드뉴스 텍스트 작성
- 포트폴리오 슬라이드 스크립트
- 소셜 미디어 카피
- 비디오 대본

## 입력 스키마
```json
{
  "task": "콘텐츠 작성 요청",
  "content_type": "cardnews|script|copy|social",
  "requirements": {
    "format": "5장 카드 / 1분 영상 등",
    "tone": "전문적|친근한|캐주얼",
    "target_audience": "페르소나 이름",
    "key_messages": ["메시지 1", "메시지 2"]
  },
  "research_input": {
    "research_report": "리서치 에이전트 결과물",
    "personas": []
  },
  "constraints": {
    "time_limit_hours": 5,
    "character_limit": null,
    "word_limit_per_card": 50
  }
}
```

## 출력 스키마
```json
{
  "content": {
    "cardnews": [
      {
        "card_number": 1,
        "title": "카드 제목",
        "body": "본문 텍스트",
        "cta": "클릭유도문안 (선택사항)"
      }
    ],
    "script": {
      "duration": "1:50",
      "sections": [
        {
          "type": "hook|problem|solution|cta",
          "text": "스크립트 텍스트",
          "timing": "0:00-0:15"
        }
      ]
    }
  },
  "notes": "작성 배경 및 선택 이유",
  "word_count": 0,
  "revision_suggestions": []
}
```

## SLA
- **소요 시간:** 4-5시간
- **병렬 처리:** 불가 (Research Agent 완료 후 시작)
- **산출물 형식:** JSON + 마크다운

## 주요 업무

### 1. 카드뉴스 텍스트
```
구성:
- Card 1: 표지 (제목 + 한 문장 훅)
- Card 2-4: 본문 (카드당 1 메시지)
- Card 5: CTA (연락처, 웹사이트)

규칙:
- 카드당 최대 50자 (제목 제외)
- 한 문장은 한 메시지
- 불릿 포인트 활용
- "왜"를 먼저, "어떻게"를 나중에
```

### 2. 비디오 스크립트
```
구조:
1. Hook (0-5초): 주의 끌기
2. Problem (5-15초): 문제 정의
3. Solution (15-45초): 3가지 해결책
4. CTA (45-50초): 행동 유도

예: "포트폴리오 1분 50초 영상"
- Hook: "로컬의 좋은 상품, 세상에 알리고 싶으신가요?"
- Problem: "디자인 비용 높음 / 온라인 판매 어려움"
- Solution: "브랜딩 / 패키지 / 판매채널"
- CTA: "Qoomee Studio와 함께하세요"
```

### 3. SNS 카피
```
규칙:
- 첫 문장이 후킹 (뉘앙스 있음)
- 실질적 가치 전달
- 이모지 활용 (과하지 않게)
- 해시태그 10-15개
- CTA 포함 (링크, 팔로우, 댓글)

예: 카드뉴스 SNS 소개
"로컬 제품, 세상에 알리는 방법을 아시나요?
브랜딩부터 판매까지, Qoomee가 함께합니다. 👇"
```

## 톤앤매너 가이드
- **기본:** 명확하고 친근함
- **Qoomee:** 전문성 + 접근성
- **타깃 고객:** 존중과 공감

### 피해야 할 표현
- 과장 ("세계 최고", "반드시")
- 검증 안 된 수치
- 일반적 고민만 반복
- 너무 캐주얼한 표현

### 권장 표현
- "함께", "연결", "매력"
- 구체적 사례 (포트폴리오 기반)
- 고객이 얻게 될 이점
- 명확한 다음 단계
